# 桌面宠物开发路线图

## 目标

做一个轻量、跨平台、可扩展的桌面宠物。

优先级：

1. Mac / Windows 都能跑
2. 保持桌面常驻体验轻量
3. 宠物动作反馈有趣
4. 先做固定 IP 版，再开放 DIY 入口

## MVP 定义

### 必须有

- 宠物悬浮在桌面
- 可拖拽
- 拖动时有弹跳和惯性
- 松手后有重力和落地反馈
- 单击打开小面板
- 番茄钟
- 喝水提醒
- 站立提醒
- 基础状态变化

### 暂时不做

- 账号系统
- 云同步
- 社交排名
- 复杂养成树
- 商店系统

## 第一阶段

### 1. 桌面壳子

目标：

- 跑起透明窗口
- 宠物可以显示
- 窗口能置顶
- 支持拖动

验收：

- 桌面启动后就能看到宠物
- 宠物不会挡住正常操作

### 2. 宠物物理

目标：

- 拖动跟随
- 左右弹跳
- 松手后回落
- 落地回弹

验收：

- 拖快时能感到“软弹”
- 往上拎起松手会掉下去
- 到底部不会穿透

### 3. 面板

目标：

- 点击打开
- 有番茄钟、喝水、站立三个模块
- 可以设置参数

验收：

- 面板打开和关闭不卡顿
- 功能入口清晰

## 第二阶段

### 4. 状态和提醒

目标：

- 宠物能根据时间切换状态
- 提醒时有对应动作

验收：

- 番茄钟结束能触发庆祝
- 喝水/站立提醒不会太打扰

### 5. 配置系统

目标：

- 保存用户设置
- 保存宠物位置
- 保存提醒间隔

验收：

- 重启后设置仍然存在

## 第三阶段

### 6. IP 定制

目标：

- 接入你提供的 IP
- 把 IP 宠物化
- 保留原角色特征

验收：

- 一眼能看出来源 IP
- 但也有桌宠化后的亲和感

### 7. DIY 入口

目标：

- 用户自己选形状、颜色、配件、表情
- 生成自己的宠物

验收：

- 用户可以不依赖开发者改图
- 配置可以导出和导入

## 推荐节奏

- 第 1 周：壳子 + 宠物拖拽物理
- 第 2 周：面板 + 番茄钟
- 第 3 周：喝水 / 站立提醒 + 状态系统
- 第 4 周：IP 美术接入 + 打磨动效

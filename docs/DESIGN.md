# 桌面宠物 Mac 版 v1 设计稿

## 1. 产品定位

做一个“陪伴型效率宠物”，不是单纯的桌面挂件，而是会根据你的专注、喝水、站立等行为产生反馈的桌面伙伴。

这一版先做 Mac 端，目标是：

- 常驻桌面，不打扰
- 点开有一个轻量面板
- 能完成番茄钟、喝水提醒、站立提醒
- 形象有记忆点，交互有一点“养宠物”的乐趣
- 后续能平滑扩展到 Windows / Linux / iPad 等版本

## 2. 宠物概念

### 名称建议

- 灵元素
- 四象灵宠
- 元素核
- Element Pet

### 形象方向

建议做一个“元素风漂浮灵宠”：

- 核心轮廓：一个小型漂浮精灵球/晶核/火焰泡泡
- 主元素：四元素混合，但以一个主元素为当前状态表现
- 视觉风格：半透明、发光、轻微粒子、边缘有流动感
- 性格感：安静时像悬浮的小灵体，活跃时会有短促的跳跃、旋转、抖动

### 元素状态

- 火：适合专注模式，热情、加速、光效偏暖
- 水：适合提醒和恢复，柔和、流动、波纹感
- 风：适合待机和轻提醒，轻盈、飘动、羽化边缘
- 土：适合稳态和坚持，沉稳、厚重、低频呼吸

### 建议的默认形态

默认用“火 + 风”的混合态：

- 识别度高
- 在桌面上显得活跃
- 适合番茄钟这种效率场景

## 3. Mac 端桌面呈现

### 常驻形态

- 宠物以一个小浮窗形式停在桌面角落
- 默认无边框、无标题栏、透明背景
- 鼠标悬停时轻微放大
- 空闲时每 6-12 秒做一次微动作

### 交互入口

- 单击：打开小面板
- 拖拽：移动宠物位置
- 右键：快捷菜单
- 长按或双击：触发“情绪动作”

### 桌面行为

- 不抢焦点，尽量不遮挡输入
- 可吸附在屏幕边缘
- 支持置顶和自动避开全屏应用

## 4. 点击后的面板设计

面板大小建议控制在一个轻量卡片，避免像完整应用窗口。

### 面板结构

#### 顶部

- 宠物头像/状态条
- 当前状态文案，例如：
  - “今天专注了 1 小时 20 分钟”
  - “该喝水了，我盯着你呢”
  - “站起来活动一下，我帮你记着”

#### 中部主功能

采用三个核心卡片：

1. 番茄钟
2. 喝水提醒
3. 站立提醒

#### 底部

- 宠物情绪值
- 今日完成度
- 快速设置入口

## 5. 番茄钟设计

### 基础功能

- 默认 25 / 5
- 可自定义专注和休息时长
- 支持长休息模式
- 支持暂停、继续、结束

### 有趣的表现

- 开始专注时，宠物进入“充能态”
- 专注中，宠物会缓慢积蓄光芒
- 倒计时最后 1 分钟，宠物开始轻微闪烁
- 专注完成，宠物弹出一个小庆祝动作
- 休息时，宠物恢复呼吸感动画

### 视觉语义

- 专注阶段：火焰/能量环
- 休息阶段：水波/雾气/柔光
- 完成阶段：彩色粒子散开

## 6. 喝水提醒设计

### 交互

- 设定提醒间隔，例如 30 / 45 / 60 分钟
- 到点后宠物会轻轻晃动并出现小气泡提示
- 点击“我喝了”后，宠物喝水动画播放

### 反馈

- 连续完成喝水提醒会积累“补水连击”
- 断掉一段时间后，宠物会变得有点委屈，但不强打扰

### 趣味化建议

- 喝水不是简单的通知，而是“给宠物补水”
- 每次确认后，宠物会显得更明亮一点

## 7. 站立提醒设计

### 交互

- 设定久坐阈值，例如 45 / 60 / 90 分钟
- 到点后宠物会“站起来”或者伸展身体
- 提醒文案偏轻松，不要像系统强提醒

### 动作反馈

- 宠物从漂浮姿态变成短暂的“伸展姿态”
- 周围出现拉伸线条或风的轨迹
- 用户点击确认后，宠物恢复漂浮

### 语气建议

- “起来动一下，我陪你”
- “别一直粘在椅子上”
- “活动 2 分钟，回来继续”

## 8. 情绪系统

为了让它更像宠物，建议加一个简单情绪系统：

- 活力值
- 专注值
- 水分值
- 站立值

### 情绪状态

- 开心：完成提醒，活跃发光
- 安静：正常待机
- 期待：等待你点击面板
- 委屈：提醒被忽略太久
- 认真：专注模式中

### 目的

不是做复杂养成，而是让宠物对你的行为有可见反馈。

## 9. 视觉语言

### 颜色

- 主色建议：熔金橙、深蓝紫、青绿、微光白
- 默认主元素可以根据时段轻微变化
- 深色桌面背景下会更有存在感

### 材质

- 半透明玻璃感面板
- 毛玻璃 + 柔和阴影
- 元素粒子轻微漂浮

### 字体

- Mac 端建议使用系统字体为主，确保清晰和兼容
- 标题可以略圆润，正文保持中性

## 10. 版本兼容策略

为了后续支持多平台，建议把架构拆成三层：

### 共享层

- 宠物状态机
- 计时器逻辑
- 提醒规则
- 用户配置

### 平台适配层

- Mac 桌面窗口
- 开机启动
- 通知权限
- 托盘 / 菜单栏入口

### 表现层

- 宠物动画
- 面板 UI
- 交互反馈

### 好处

- Mac 版先上线
- 后续换平台只换窗口和系统能力
- 宠物行为逻辑保持一致

## 11. Mac 版首发建议范围

### 必做

- 桌面宠物悬浮
- 单击打开面板
- 番茄钟
- 喝水提醒
- 站立提醒
- 基础宠物动画状态切换

### 先不做

- 复杂养成数值
- 社交排行
- 账号系统
- 大型商店系统

## 12. 推荐的一版命名与卖点

### 版本名

Elemental Pet Mac v1

### 一句话卖点

一个会陪你专注、提醒你喝水和站起来的元素灵宠桌面伙伴。

# 宠物 DIY 入口设计

## 目标

让用户不需要开发者介入，也能生成自己的桌面宠物。

## 核心思路

把 DIY 做成一个“可视化配置器 + imagegen 生成器”。

用户看到的是：

- 选择风格
- 选择颜色
- 选择表情
- 选择配件
- 选择元素
- 预览结果

后台做的是：

- 把用户选择转换成结构化配置
- 根据配置拼接 prompt
- 调用 imagegen 生成宠物资产
- 生成桌宠使用的基础图和动作图

## 建议的 DIY 入口流程

### 第一步：选模板

- 元素风
- 毛绒风
- 果冻风
- 机械风
- 幻兽风

### 第二步：选主体

- 圆球
- 小精灵
- 小动物
- 植物生物
- 机械核心

### 第三步：选关键特征

- 眼睛
- 嘴型
- 头顶装饰
- 主色
- 发光程度

### 第四步：预览和生成

- 先出静态图
- 再出动作帧
- 最后组装成宠物包

## 数据结构建议

```json
{
  "style": "elemental",
  "body": "round_orb",
  "primaryColor": "#FF8A2A",
  "secondaryColor": "#8BC34A",
  "eyes": "blue_round",
  "mouth": "cute_smile",
  "accessory": "leaf_crown",
  "element": "fire",
  "material": "soft_fuzzy",
  "glow": true
}
```

## UX 要点

- 不要让用户一上来面对太多参数
- 先给 3 到 5 个预设模板
- 高级参数折叠到“更多设置”
- 生成失败时给可读错误，而不是只显示系统报错
